## 2. DIGITAL PLATFORM & TECHNICAL ARCHITECTURE

### 2.1 Technology Stack
*   **Framework**: React 18+ (Single Page Application - SPA)
*   **Build Tool**: Vite (Lightning fast HMR & Bundling)
*   **Hosting Compatibility**: Vercel (`vercel.json`), Netlify (`netlify.toml`)
*   **Styling**: Vanilla CSS (Modular, Optimized)
*   **Animation**: Hybrid approach – CSS Keyframes for LCP (Largest Contentful Paint) optimization, `framer-motion` (Lazy loaded) for decorative elements.

### 2.2 Site Structure (Sitemap)
*   **Home (`/`)**: Landing page. Hero section, "Why Choose Us" teaser, Tools Marquee.

### 2.3 Performance Engineering (Optimization Specs)
*   **Core Vitals Target**: Desktop Score 95+, Mobile 95+, Accessibility 100.
*   **Load Strategy**: 
    *   **Route-Based Code Splitting**: All pages lazy-loaded via `React.lazy()` and `Suspense`.
    *   **Critical Rendering**: Home Hero loads synchronously; heavy JS (`framer-motion`) is deferred.
    *   **Font Optimization**: `font-display: swap` enforced.
*   **Accessibility (WCAG AA)**: 
    *   High contrast ratios (4.5:1+).
    *   ARIA labels on all interactive elements (VoiceOver compatible).
    *   Keyboard navigable.

### 2.4 SEO Strategy
