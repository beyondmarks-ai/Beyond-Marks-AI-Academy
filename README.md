# Beyond Marks AI Academy

## 🚀 Overview

**Beyond Marks AI Academy** is a cutting-edge educational platform designed to shift the focus from traditional rote learning to **AI Literacy** and **Skill Mastery**. 

In an era where AI can solve standard problems in seconds, we empower the next generation to become **creators, strategic thinkers, and innovators**.

## ✨ Features

- **Modern UI/UX**: Built with a "Glassmorphism" design language, featuring smooth gradients and interactive elements.
- **Dynamic Animations**: Powered by `framer-motion` for a premium, fluid user experience.
- **Responsive Layouts**: Fully responsive design supporting all device sizes.
- **Component Architecture**: Modular and reusable React components.
- **Curriculum Showcase**: detailed breakdown of courses and skills.

## 🛠 Tech Stack

- **Frontend**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Clean CSS with Modern Variables & Modules
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/beyond-marks.git
   cd beyond-marks
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

## 🏗 Build

To create a production build:

```bash
npm run build
```
